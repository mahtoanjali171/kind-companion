# CampusFlow

A responsive frontend campus assistant for exploring student events, learning resources, clubs, announcements and campus locations. Built with React, TypeScript, TanStack Start, Tailwind CSS and reusable UI components.

## Getting started

```bash
bun install
bun run dev
```

Open the local address printed by the development server.

## What works

- Search across all five campus content categories, with category and date filters where relevant.
- Browse details and locally bookmark event and resource cards during the current visit.
- Explore route-specific pages on mobile and desktop.

All listings are sample content in `src/data/campus.ts`. Registration, downloads, club membership and login are not connected to a service yet. Replace the sample data with real campus records when an API is available.
